DSH Model Search Plugin Demo

模型选择器演示

这个演示展示了一个模拟的DSH模型选择器，集成了关键字搜索功能。

当前选择: 未选择

使用说明：

  • 点击"初始化搜索插件"按钮启用搜索功能
  • 在搜索框中输入关键字（如：gpt、claude、开源等）
  • 按ESC键清除搜索
  • 按Ctrl+F聚焦搜索框
  • 点击"测试搜索功能"测试搜索高亮

代码示例

import { ModelSearchPlugin } from 'dsh-model-search-plugin';

// 创建插件实例
const plugin = new ModelSearchPlugin({
    placeholder: '搜索模型...',
    hotkeyEnabled: true,
    searchHotkey: 'Ctrl+F',
    debounceDelay: 300,
    hideUnmatched: true
});

// 初始化插件
plugin.initialize();
